# Screenshots

Figma MCP Starter đã đạt giới hạn nên PNG mới không được tự động tải vào gói này.

## Export thủ công từ Figma

Với từng frame:

1. Mở link frame trong `FIGMA_HANDOFF.md`.
2. Chọn frame.
3. Ở panel phải, tìm phần **Export**.
4. Chọn PNG, scale `2x`.
5. Export và đổi tên đúng danh sách bên dưới.
6. Chép ảnh vào thư mục này.
